# Управление камерой · версия 2

Flutter-приложение с общим экраном Windows/Android. Сейчас реализован **деморежим**, без отправки команд по BLE. Показанные углы — модель, а не измерения машины.

Стаканы поворачиваются вокруг центральных осей в диапазоне 0–90° по часовой стрелке. Удержание стрелки запускает движение, отпускание останавливает. Мешалка включается и выключается одной кнопкой. «Остановить всё» останавливает анимации.

## Запуск на Windows

Установить Flutter stable и Visual Studio с workload Desktop development with C++. Затем из этой папки:

```powershell
flutter pub get
flutter run -d windows
flutter build windows
```

## Android

Целевое устройство: Lenovo TB-X304L, Android 7.1.1 (API 25). Установить Android SDK, подключить планшет с USB debugging:

```powershell
flutter devices
flutter run -d <device-id>
flutter build apk --release --target-platform android-arm
```

Общий Dart-код используется без переноса экрана. Отдельная работа потребуется для BLE-адаптеров, разрешений Android и проверки на устройстве. ARM32 обязателен для целевого планшета; minSdk настроен на 24.
